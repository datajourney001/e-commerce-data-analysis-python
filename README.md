# E-Commerce Sales & Profit Analysis 📊

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on an e-commerce sales dataset using Python. The goal is to uncover actionable insights into revenue trends, product performance, and overall profitability.

## 🛠️ Tools & Technologies Used
*   **Language:** Python
*   **Libraries:** Pandas, Matplotlib, Seaborn
*   **Environment:** Jupyter Notebook

## 🎯 Key Analytical Questions Solved
1. Monthly Sales Analysis (Highest & Lowest revenue months).
2. Category-wise Sales Analysis.
3. Sub-Category Analysis.
4. Monthly Profit Analysis.
5. Profitability by Category & Sub-Category.
6. Sales & Profit by Customer Segment.
7. Overall Sales-to-Profit Ratio.
